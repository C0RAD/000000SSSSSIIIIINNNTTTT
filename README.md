An OSINT (open-source intelligence) project focused on collecting, correlating, and documenting information from lawfully accessible public sources.

## Project documentation

- [Project overview](docs/PROJECT_OVERVIEW.md)

## Guiding principles

- Preserve source attribution and retrieval timestamps.
- Separate verified observations from inferred relationships.
- Use public sources and documented APIs in accordance with their access rules.
- Respect privacy, rate limits, and data-retention requirements.

## Status

Early planning. The implementation language, framework, storage layer, and deployment model have not yet been selected. See the [roadmap](docs/ROADMAP.md) for proposed next steps.
