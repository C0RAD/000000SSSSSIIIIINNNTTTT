## Guiding principles

- Preserve source attribution and retrieval timestamps.
- Separate verified observations from inferred relationships.
- Use public sources and documented APIs in accordance with their access rules.
- Respect privacy, rate limits, and data-retention requirements.

## Status

The static Nightwatch frontend and an initial Node.js backend integration scaffold are in place. See the [backend setup guide](docs/PROVIDER_SETUP.md) to configure server-side provider credentials. Live provider use requires local backend setup or a separately deployed API.
